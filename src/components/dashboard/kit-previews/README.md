# Kit previews

## Purpose

Small illustrative previews of each kit shown on the dashboard. Buttons and `cn` come from `@merqo/ui/primitives`.

## Contents

- `index.ts` — `KIT_PREVIEWS`, a map from kit slug to its preview component.
- `mockup-window.tsx` — chrome-frame wrapper that holds a few real domain objects, not a fake screenshot.
- `qkit-preview.tsx` and `loopkit-preview.tsx` — the per-kit preview bodies.
