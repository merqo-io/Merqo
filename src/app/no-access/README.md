# No access

Explains missing Merqo-team access and offers sign-in, sign-out or a team-access retry. The page reads the current session for its message and uses the shared brand Wordmark. The admin server boundary owns authorization; this explanation page does not grant access.

Buttons, inputs, labels, selects, switches and tooltips used here, and cn, are imported from `@merqo/ui/primitives`; there are no local copies.
