# Subprocessors

Third parties that process personal data for the Merqo kits, or sit in the path of it. Matches the sub-processor list in the published privacy policy, plus providers found in the kits' `package.json` and `.env.example` files. Data categories refer to the [data inventory](2026-10-24-data-inventory.md).

Region and DPA entries marked "To confirm" cannot be verified from repository config and need the owner to check the provider dashboard or signed terms.

printkit label printers (NIIMBOT) are local devices with no known cloud transfer, so they are not listed.

No email, SMS or analytics provider appears in any kit's `package.json` or `.env.example`. If one is added, add a row before it goes live and update the privacy policy.

Tesseract OCR in paykit (`tesseract.js`, language data bundled in `ocr-data/`) runs inside paykit's own Vercel function. It is not a subprocessor and sends nothing to a third party.

## Maintenance

- Add a row before integrating any new provider.
- Review the table whenever a kit adds a dependency or env var that points at an external service.
- Keep the list in step with the privacy policy in `merqo-ui`.
